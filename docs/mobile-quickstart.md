# Mobile status and recovery

Notework AI 0.4.8 is **desktop-only**. Mobile is under active development and currently disabled. There is no promised mobile delivery date. The current plugin declares desktop-only compatibility and blocks mobile startup.

Historical mobile images, transport modules and synthetic fixtures are development evidence. They do not establish an enabled phone release, a physical-device installation, or live phone provider inference. Do not use them as a current installation guide.

## If an older copy is installed on your phone

1. Disable Notework AI on the phone in Obsidian's Community Plugins settings. Updating the PC does not remotely disable an older phone copy.
2. In Sync settings on both PC and phone, turn off **Active community plugin list** and **Installed community plugin list**. Ordinary Markdown note Sync can continue.
3. Preserve notes, settings and private indexes before making recovery changes. Do not delete your vault to solve a plugin startup issue.

If a vault fails to open, work from a preserved copy and compare a working vault with the failing one. Plugin isolation and a user-confirmed successful reopen are separate from proof that a modified Notework build starts on a physical phone. Seek scoped help with sanitized details rather than sharing credentials or private notes.

Retained knowledge export/import helpers are experimental. They do not enable phone use in this version. Existing exports or mobile caches may contain private note excerpts and vectors; treat them as private vault data. [Security policy](../SECURITY.md).

Use the [desktop guide](getting-started.md) for the supported release.
